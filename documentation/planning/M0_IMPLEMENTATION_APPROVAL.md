## What counts as approval and completion

**Implementation-start decision:** APPROVE M0-A and the bounded subsequent slice process / REQUEST CHANGES with concrete blockers / HOLD with missing evidence or decision owner. Record reviewer/user identity, scope, date and conditions when an actual response arrives; this packet is not that response.

**M0 acceptance:** a reproducible release candidate with all applicable current-flow critical regressions executed, meaningful negative and success assertions, stock/money/document reconciliation, safe provider/DB isolation, required correctness indexes and unresolved blocker list empty for that scope. At least one regression must fail with each corrected critical defect reintroduced; cleanup, skips, a stubbed verifier or saved HTTP200 cannot certify the fix.

**Pilot/release approval:** additional staffed synthetic journeys, clinical/operations/provider decisions, privacy/security obligations, current restore admission/local-effect recovery and measured canonical100 aggregate HTTP RPS profile with queue/integrity evidence. Phone call concurrency is separate. No production, measured-capacity or complete-schema approval is implied by implementation start.
