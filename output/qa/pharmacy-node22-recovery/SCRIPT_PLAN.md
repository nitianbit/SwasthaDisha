# Fixed operator plan — data only

This plan is not an executable operator. Implement one Python standard-library script only after both recipe decisions, then freeze/review its exact source and invocation before acquisition. Python may read its trusted standard library and fixed recipe inputs; no imported project/package/application code. No subprocess/shell except an explicitly reviewed external deadline supervisor if required; it must launch Python only, never Node. The current recipe supplies no such invocation authority.

1. Freeze local interpreter/launcher path, complete executable hashes and required stdlib provenance in activation review. Require macOS arm64 from OS metadata. Reject unexpected script arguments and inherited preload/proxy/TLS override variables before network or allocation. Build a fresh minimal process environment; ignore ambient HTTP(S)_PROXY/ALL_PROXY/NO_PROXY, NETRC and user config. Standard TLS verification stays enabled. Reject a future operator whose own script/recipe hashes differ.
2. Open the literal real `/private/tmp` with no symlink traversal using descriptor-relative operations. Refuse `/private/tmp/m0-node22` if lstat finds any object, including a symlink, even with matching bytes/marker. Refuse existing activation-evidence paths. Create a fresh random stage `sd-pharmacy-node22-stage-<random>` using exclusive mkdir0700, capture device/inode/uid plus a held directory fd in private memory, then create the canonical directory exclusively0700 and capture the same private identity. Revalidate the path and fd identity before each phase/mutation. A racing creator causes refusal; no existing directory is adopted or deleted.
3. Create exactly the allowlisted stage files `SHASUMS256.txt`, `archive.tar.gz`, `node.part` and `outcome.json`, each via openat O_CREAT|O_EXCL|O_NOFOLLOW mode0600. Use fstat to require regular files, expected uid and nlink1, retaining their device/inode identities. No caller-supplied filename, temp file search, glob, package tree or archive-derived destination. Outcome publication uses an exact fresh review-bound evidence filename; retain no secrets or operational config.
4. Arm the absolute process300s deadline and phase deadlines with a reviewed watchdog that interrupts DNS/TLS/reads/decompression. Reserve <=10s for identity-safe cleanup; a deadline breach cannot be recovered by retrying. Use direct HTTPSConnection to fixed nodejs.org port443, default trusted CA context with hostname verification, exact literal URL path, GET and no credentials/cookies/redirect following. Ignore proxy configuration. Socket connect/read10s/5s and all absolute phase limits apply. Reject non200,3xx, content encoding other than absent/identity and conflicting/invalid Content-Length. If Content-Length exists enforce <=body cap and exact measured equality; if absent stream to EOF under cap. Count actual streamed bytes before each write, including chunked responses; no automatic decompression by HTTP client.

A failure consumes this proposed single attempt; exact subsequent source/recipe changes and any retry need fresh review.
