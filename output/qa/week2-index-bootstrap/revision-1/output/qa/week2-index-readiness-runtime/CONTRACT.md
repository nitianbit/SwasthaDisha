## Appendix A: finite internal matrix and result notation

The table below and pin-intents.json are exactly the same finite set; uniqueness
and the declared cardinalities must be checked before trial execution. M0 is the
fixed13/eight projected manifest; O0 is the complete actual private readback.
Every selected-data trial starts from a fresh descriptor-safe copy of M0/O0 and
changes ONLY the stated field. Row selection is fixed collection ordinal and
implicit index0/explicit index1, matched against exact literal key/name data;
zero/multiple selected rows is fixture failure, not a skipped trial. Removing
an observed index never mutates the real database. G(p) is a purely synthetic
one-collection manifest named fixture, explicit key [[value,1]] with partial p,
and completed_id/value specs carrying the same p; it triggers no namespace/DB
access. D(n) is n nested own 'a' objects ending in true, with the root at depth0.

Expected notation R means {true,READY,null,null}; M/O/X mean
{false,MANIFEST_INVALID/OBSERVATIONS_INVALID/INPUT_INVALID,null,null}.

always exactly ready,code,collectionOrdinal,indexOrdinal in a fresh frozen plain
result. No expected result is computed by the application helper under test.

prepared recursively frozen plain object/array data; opaque marker/native values

are frozen in the second mode. The reflection-throw Proxy trial is ONE ordinary
run because freezing it would itself trigger reflection before the helper; its
owned target is snapshotted separately and exactly one expected reflection trap
is recorded. All other getters/coercions must stay0. Both success and refusal
inputs/results receive descriptor/prototype/order/reference safe immutability

fixtures may exceed application bounds in private test data only, and remain
bounded by the fixture's32768-node/131072-string-unit construction guard.
